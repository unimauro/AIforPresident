# AI for President

Plataforma web que compara candidatos presidenciales con una IA hipotética, mostrando encuestas en tiempo real, propuestas y análisis.

## Deploy

**URL en producción:** https://unimauro.github.io/AIforPresident/

Desplegado automáticamente vía GitHub Pages desde la rama `main`.

## País activo

- **Perú** — Elecciones Generales 12 de abril 2026

## Estructura de datos (Perú)

| Archivo | Contenido |
|---|---|
| `data/peru/polls.json` | Encuestas (Datum, Ipsos, CPI, IEP) |
| `data/peru/news.json` | Ticker, entrevistas, videos/debates |
| `data/peru/candidates.json` | 36 candidatos + Presidente IA |
| `data/peru/issues.json` | Problemas clave del país |
| `data/peru/proposals.json` | Propuestas de IA por área |
| `data/peru/statistics.json` | Estadísticas nacionales |
